## Cómo trabajo

Yo escribo el modelo: supuestos, ecuaciones y caso de validación. [Claude Code](https://claude.com/claude-code) escribe el código, los tests y la interfaz, y yo reviso cada ecuación contra la bibliografía. Cada repositorio tiene una sección **Validación** con el caso que el código reproduce y una sección **Supuestos y límites** con lo que no cubre.
